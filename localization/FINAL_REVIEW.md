## 그대로 유지한 항목

17개 보호 파일의 바이트 해시를 대조하여 기존 인용·판정·상태·에이전트 핵심 프롬프트·의존성·스키마·시작 설정이 바뀌지 않았음을 확인했습니다. `skills/api-recon/SKILL.md`와 `skills/scopesentry/SKILL.md`에는 중국어 문구가 남지 않았고, API Recon 참고 문서에는 **대상 사이트의 실제 중국어 로그인 오류를 검색하는 정규식 한 줄**만 남깁니다. 이 정규식을 번역하면 인식 동작이 바뀌므로 그대로 둡니다.

이 보완은 외부 모델의 응답 동등성이나 전체 운영 기능의 무오류를 새로 보장하는 것이 아닙니다. 전체 PostgreSQL 통합 테스트·로그인 후 E2E·외부 LLM 호출은 이번에 재실행하지 않았습니다. 이전의 `verification.json`과 실제 실행 결과는 역사 기록으로 보존합니다.

## 실행 중인 환경과 적용

운영 DB, 실제 config.json, 저장된 사용자 프롬프트, 실행 중인 서비스와 기존 실행 파일은 변경하지 않았습니다. Next.js 빌드와 Go 빌드는 저장소 밖의 별도 소스 사본에서 수행하여 기존 `.next` / `web/out` 캐시를 덮어쓰지 않았습니다.

**화면·도움말 변경은 새로 빌드한 실행 파일 또는 정적 UI를 배포할 때 적용됩니다.** 현재 실행 중인 프로그램을 자동으로 교체하거나 재시작하지 않았습니다. 변경 소스와 검증 자료는 GitHub에 반영합니다.
